# Police: Reports

Each Police force has a list of reports they offer on request. These reports are used to provide information to the public and other agencies. The reports are generated by the Police force and are available to the public on request. Each of these reports come with a set of questions that need to be answered by the requester before a formal request can be made to the relevant Police force.

## Reports

```
GET /api/v1/police/{police}/reports
```

```
Status: 200 OK
```
