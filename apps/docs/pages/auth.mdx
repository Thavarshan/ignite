# Authentication

While the API provides multiple authentication methods, we strongly recommend using JWT for production applications. The other methods provided are intended to be used for internal applications or testing.

## Basic Authentication

This API allows for the user to log in to the application through username and password.

```
POST /api/v1/login
```

### Parameters

| Name     | Type   | In   | Description                                                        |
|----------|--------|------|--------------------------------------------------------------------|
| username | string | body | **Required**. The email address the user's account is associated with. |
| password | string | body | **Required**. The password of the user.                                |

### Code Samples

```bash
curl --location --request POST 'https://api.ignite.xyz/login' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--data-raw '{
    "email": "default.user@macroactive.com",
    "password": "password"
}'
```

## OAuth Authentication

OAuth tokens include JWT, personal access tokens, and internal access tokens. These token may or may not have an expiration time and enable the user to check the last access time or revoke access at any time.

```bash=
curl -v -H "Authorization: Bearer TOKEN" https://api.ignite.xyz
```

### Via JWT Token

To generate a JWT token a user must first login through basic authentication by use of `username` and `password`. The response should return an access token in the response body.

```json
{
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJpc3MiOiJodHRwczpcL1wvbWFjcm9hY3RpdmlzdHMtYXBpLm1hY3JvYWN0aXZlbXZwLmNvbVwvYXBpXC92MVwvbG9naW4iLCJpYXQiOjE2Mzg0MTk0MjYsImV4cCI6MTYzODU5MjIyNiwibmJmIjoxNjM4NDE5NDI2LCJqdGkiOiIzWTBLVnduQjJ6SHJHakVLIiwic3ViIjoiNjFhNzNhYWUwZjZlZmM1M2E3Njg2MjIzIiwicHJ2IjoiMjNiZDVjODk0OWY2MDBhZGIzOWU3MDFjNDAwODcyZGI3YTU5NzZmNyJ9.iZKRwbm9LE_8J4i-BfZ_tlpL-DcPcY7iUQ4rCVaB1cc",
}
```

You may use this token to access auth-protected routes in the API by including the token in the `Authorization` header of the request.

JWT tokens usually expire after **2 days**.

### Via Personal Access Token

Personal Access Token works the same way JWT token does except they may or may not have an expiration time.

To generate a Personal Access Token you may run the following shell command in the base path of the API codebase.

```bash=
php artisan token:personal {email} {token-name}
```

You may use this token to access **specific** auth protected routes in the API by including the token in the `Authorization` header of the request.

### Via Internal Access Token

Internal Access Token is pre-shared tokens and is used mostly for internal application within MacroActive.

To generate an Internal Access Token you may run the following shell command in the base path of the API codebase.

```bash=
php artisan token:internal {token-name}
```

You may use this token to access **specific** auth protected routes in the API by including the token in the `Authorization` header of the request.

## Refresh Token

This endpoint allows refreshing a JWT token. This endpoint can only be accessed with a valid JWT token.

```
POST /api/v1/refresh-token
```

### Parameters

| Name     | Type   | In   | Description                                                        |
|----------|--------|------|--------------------------------------------------------------------|
| Authorization | string | header | **Required**. The JWT token of the authenticated user. |

### Response

```
Status: 200 OK
```

## Unauthenticate

This endpoint allows to logout the currently authenticated user. This endpoint can only be accessed with a valid JWT token.

```
POST /api/v1/logout
```

### Parameters

| Name     | Type   | In   | Description                                                        |
|----------|--------|------|--------------------------------------------------------------------|
| Authorization | string | header | **Required**. The JWT token of the authenticated user. |

### Response

```
Status: 204 No Content
```

```json
{

}
```

### Invalid JWT Token

```
Status: 401 Unauthorized
```

```json
{
    "message": "Bad credentials"
}
```
